# Futures Scalping Bot

Автоматическая торговля фьючерсами RTS и Si на Московской бирже.

## Описание

Бот для скальпинга фьючерсами на индекс РТС (RTS) и доллар-рубль (Si) через API Финам.

## Возможности

- Подключение к демо-счёту Финам
- Получение котировок в реальном времени
- Автоматическая торговля по стратегиям скальпинга
- Веб-интерфейс для мониторинга и управления
- Журнал сделок и статистика

## Инструменты

- Фьючерс на индекс РТС (RTS)
- Фьючерс на доллар-рубль (Si)

## Стратегии

- Импульсный пробой (RTS)
- Отскок от уровней (Si)

## Технологии

- **Backend**: Python, FastAPI, WebSocket
- **Frontend**: React, TypeScript, Tailwind CSS
- **База данных**: SQLite
- **API**: Finam Trade API

## Статус проекта

В разработке. Тестирование на демо-счёте.
